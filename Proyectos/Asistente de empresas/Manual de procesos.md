
- **Manual inicial:** modelo detallado y personalizado a medida de la empresa.
    
- **Implementación:** incluye configuración de la herramienta + primera ronda de recopilación de información de procesos.
    
- **Actualización de procesos:**
    
    - El bot detecta cuándo un usuario quiere modificar/mejorar un proceso.
        
    - Muestra vínculos de ese proceso dentro del manual.
        
    - Interactúa con el usuario hasta lograr la versión deseada.
        
- **Gestión de cambios:**
    
    - Se puede configurar qué usuarios tienen permiso para proponer o implementar cambios.
        
    - Opciones:
        
        1. Guardar sugerencias en una base paralela y revisarlas semanalmente antes de aprobar.
            
        2. Dar permisos directos a ciertos usuarios para implementar mejoras.
            
        3. **Mix** de ambas opciones (recomendado).
